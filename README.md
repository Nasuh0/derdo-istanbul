# Derdoİstanbul

İstanbul kültür ve mimarlık atlası: 62 keşif noktası, 8 kategori, 4 öneri rotası, zaman çizelgesi, Türkçe arama ve ilçe/dönem filtreleri.

Üyeliksiz keşif listesi localStorage içinde tutulur. Tarihî eserlerin tüm resmî envanteri olduğu iddia edilmez. Kategori görselleri açık biçimde işaretlenir. Güncel bilet ve saatler ilgili kurumlara yönlendirilir.

Çalıştırma: `npm start`. Node 22, harici uygulama bağımlılığı yok. `/api/health` sağlık denetimidir.

Görseller: Unsplash, Milli Saraylar ve Kültür ve Turizm Bakanlığı. Kaynaklar uygulama içindeki Kaynaklar & görseller bölümündedir.
